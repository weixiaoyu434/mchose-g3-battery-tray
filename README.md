# 迈从 G3 电量托盘（初代 G3 · 258A 方案）

在 Windows 系统托盘实时显示迈从（MCHOSE）G3 无线鼠标电量的小工具，附带本地仪表盘网页。
HID 读取基于 Python 标准库 + ctypes，运行仅依赖 `pystray` 和 `pillow` 两个第三方包。

## 支持的鼠标型号（重要，请先对照）

| 型号 | 支持情况 | 识别特征 |
|---|---|---|
| **G3 初代**（旧款，SINO WEALTH 方案） | ✅ 完整支持 | 2.4G 接收器 `VID 258A:PID 0138`；有线模式 `258A:0136`（产品名 "G3 Gaming Mouse"） |
| G3 V2 / 新版 G3（新一代固件） | ❌ 不支持 | VID `0x3837` 或 `0x5253`——请改用 [dsh-mchose-battery](https://github.com/Fransice/dsh-mchose-battery)、[mchose-linux](https://github.com/alexfrih/mchose-linux) 等新一代项目 |
| G3 Pro / G3 Ultra 等衍生型号 | ❓ 未测试 | 大概率不适用（协议族不同），欢迎反馈实测结果 |

**怎么确认自己是哪一代**：插上接收器（或插线走有线），在本目录运行
`python mouse_battery_probe.py --list`，看 VID:PID 是 `258A:0138/0136`（本项目适用）
还是 `0x3837/0x5253` 系（不适用）。初代 G3 的官方配置软件是旧版 MCHOSE HUB（Qt 版），
而新版 M-HUB（Electron）不支持它。

## 功能

- 托盘图标：电量填充（≥50% 绿 / 20–49% 黄 / <20% 红）、充电中 ⚡、已充满 ✔、离线
- 悬停显示状态；右键菜单可打开仪表盘、退出（双实例会被互斥锁自动拒绝）
- 仪表盘：`http://127.0.0.1:8765`（电量环形图 + 历史曲线 + 原始帧日志）

## 新机器部署（约 3 分钟）

1. 安装 Python 3.12+（官网安装包，勾选 Add to PATH）
2. 双击 `安装依赖.bat`（安装 pystray + pillow，走阿里云镜像）
3. 双击 `启动G3电量托盘.vbs` 测试（无控制台窗口，图标出现在托盘）
4. 双击 `安装开机自启.vbs`（在 Startup 文件夹创建快捷方式）
5. 插上 2.4G 接收器，完成。仪表盘地址 `http://127.0.0.1:8765`

> 项目文件夹可以放在任何位置；挪动后重新双击一次 `安装开机自启.vbs` 即可。

## 已知特性与限制

- 电量主数据源：接收器每 ~48 秒的广播帧；连接后托盘会主动发起即时查询
  （成功条件不稳定，失败时静默回退到广播，不影响使用）
- **有线充电模式下固件不提供电量**（官方软件同样拿不到），托盘只显示"充电中"
- 拔线回到 2.4G 后 48 秒内恢复实时显示
- 鼠标休眠时不广播，动一动鼠标即可刷新

## 协议摘要（逆向自官方旧版 MCHOSE HUB 的 USB 流量）

- 广播：`0xFF02/0x02` 集合 Input Report rid 0x09，每 ~48s：`[09 0A 05 电量% 00×4]`
- 查询：同集合 Feature rid 0x09，SET 521B = `[09] + [09 0C 09 01 01 00 01 00] + 512×00`，
  GET 521B 响应字节 8 = 电量%（**缓冲区必须 521 字节**，按 caps 的 520 构建会被设备 NAK）
- MAC/序列：`0xFF01/0x01` 集合 Feature rid 0x0A → `[06, MAC×6, 00]`
- 接收器 VID:PID = `258A:0138`（2.4G），有线模式 `258A:0136`（"G3 Gaming Mouse"）
- 完整探测工具：`python mouse_battery_probe.py --help`（--list / --battery / --feat / --setfeat）

## 故障排查

- 日志：同目录 `tray.log`（自动重建，超 1MB 自动清理）
- 图标不见了：检查托盘折叠区（^），可拖出固定
- 收不到电量：确认鼠标开机且在 2.4G 模式；动一动鼠标唤醒
- 修改仪表盘样式：直接编辑 `dashboard.html`，刷新页面即生效，无需重启
